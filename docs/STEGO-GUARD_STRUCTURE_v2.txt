УПРАВЛЕНИЕ:
  Подъём:      cd deployments && docker compose up -d
  Остановка:   docker compose down
  Пересборка:  docker compose up -d --build [<service>]
  Логи:        docker compose logs <service>
  E2E:         cd ml-service && python scripts/e2e_check.py   (требует запущенных сервисов)
  Тесты:       cd ml-service && python -m pytest tests/ -v
  Go-тесты:    cd api-gateway && go test ./test/
